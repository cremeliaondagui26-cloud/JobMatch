# JobMatch

Projet de base pour explorer, nettoyer, analyser et modeliser des donnees liees au matching emploi-candidat.

## Structure

- `data/` contient les donnees brutes et preparees.
- `notebooks/` contient les notebooks d'exploration et de modelisation.
- `src/` contient la logique Python reutilisable.
- `app/` contient l'application Streamlit.
- `models/` contient les modeles sauvegardes.
- `tests/` contient les tests.

## Installation

```bash
pip install -r requirements.txt
```

## Lancer l'application

```bash
streamlit run app/app.py
```
